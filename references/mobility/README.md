# Mobility References

## Core Sources

### Becoming a Supple Leopard — Kelly Starrett
The mobility bible. Systematic approach to movement quality, tissue maintenance, and position-based diagnostics.
- Joint-by-joint mobilization protocols
- Movement archetypes (squat, hinge, press, overhead)
- Upstream/downstream thinking for pain and restriction

### Key Concepts
- **Sliding surfaces**: Tissue health is about restoring sliding between layers, not just "stretching"
- **Position before load**: Fix the position first, then add weight
- **10-minute mobility rule**: Daily minimum effective dose
- **Test/retest**: Always benchmark ROM before and after mobilization
