# Breathwork References

## Core Sources

### The Oxygen Advantage — Patrick McKeown
Nasal breathing, CO2 tolerance, and the BOLT (Body Oxygen Level Test) score as a trainable metric.
- BOLT score: exhale, pinch nose, time until first urge to breathe. Target: 40s+
- Nasal breathing during training improves CO2 tolerance over time
- Light breathing exercises for recovery and parasympathetic activation

## Tools
- **Othership** — Guided breathwork sessions (active tool)
- **Apple Watch** — HRV tracking as proxy for autonomic state

## What to Track
- Session consistency (frequency, duration)
- BOLT score progression
- Pre/post HRV delta from sessions
- Breath hold benchmarks (comfortable hold, max hold)
