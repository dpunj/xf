# Meditation References

## Core Sources

### Right Concentration — Leigh Brasington
Practical jhana manual. Clear instructions for accessing absorption states in retreat and daily practice.
- Jhana 1–4: form jhanas (progressive refinement of attention)
- Jhana 5–8: formless jhanas
- Access concentration as prerequisite — stable, unforced attention

### The Mind Illuminated — Culadasa (John Yates)
Staged meditation progression with clear benchmarks per stage.
- 10 stages from establishing a practice to shamatha
- Useful for knowing where you are and what to work on next
- Integrates attention and awareness as distinct skills

- Jhana access (which jhanas, reliability, session context)
- Stage progression (TMI framework)
