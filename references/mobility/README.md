## Key Principles

- **Position before load**: fix position first, then add weight
- **Bracing sequence**: glutes → ribcage down → belly tight → head
  neutral → shoulders set. Universal setup for every loaded movement
- **Upstream/downstream**: pain site is rarely the source. Check above
  and below the restriction
- **Sliding surfaces**: tissue health is about restoring sliding
  between layers, not just "stretching"
- **10-minute rule**: daily minimum effective dose for body maintenance
  (Starrett recommends 15-20 min)
- **Test/retest**: always benchmark ROM before and after mobilization.
  No measurable change = wrong target
