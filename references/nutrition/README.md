# Nutrition References

Actionable nutrition defaults for Divesh: 150 lb CrossFitter, lactose intolerant, rebuilding consistency, and using drinks/shakes as a reliability anchor when home food is chaotic.

## Core Targets

- **Protein:** 120-150 g/day
  - Science-backed range for 150 lb / ~68 kg: ~1.6-2.2 g/kg/day
  - Practical CrossFit target: hit **120g+** most days, push toward 150g when training hard
- **Reliability first:** one dependable shake beats theoretical perfect meals
- **Real food base:** rice, eggs, meat, lentils, beans, fruit
- **Hide greens:** smoothies/sauces beat forcing sad salads
- **Hydrate for Panama + CrossFit:** water, salt, lime, coconut water as needed

## Current Default

One **strength shake per day** for 7 days:

- Orgain/Vega plant protein
- banana
- rolled oats
- peanut butter
- baby spinach
- cinnamon
- oat milk
- optional creatine monohydrate

Use it at noon, post-CrossFit, or whenever food reliability starts slipping.
